# Low-memory Unreal build\n\nIf Visual Studio reports C3859 (Failed to create virtual memory for PCH), C1076 (internal heap limit reached), or C1060 (compiler is out of heap space), the failure is caused by insufficient available commit/virtual memory during parallel C++ compilation.\n\n## Windows page file\n\nClose Unreal Editor and Visual Studio, then open:\n\nSystem Properties > Advanced > Performance > Settings > Advanced > Virtual memory > Change\n\nRecommended:\n\n- Prefer System managed size on an SSD with plenty of free space.\n- If the failure continues, use Initial size 32768 MB and Maximum size 65536 MB.\n- Restart Windows after changing the page-file configuration.\n\n## Low-memory build helper\n\nRun Scripts/Build-LowMemory.ps1 from PowerShell. It limits UnrealBuildTool to two parallel compiler actions by default.\n\nExample:\n\n    powershell -ExecutionPolicy Bypass -File .\\Scripts\\Build-LowMemory.ps1\n\nFor a different engine path:\n\n    powershell -ExecutionPolicy Bypass -File .\\Scripts\\Build-LowMemory.ps1 -EngineRoot "D:\\GameDev\\UE_5.8"\n\nFor a very memory-constrained PC:\n\n    powershell -ExecutionPolicy Bypass -File .\\Scripts\\Build-LowMemory.ps1 -MaxParallelActions 1\n\n## Clean rebuild\n\n1. Close Unreal Editor and Visual Studio.\n2. Delete Intermediate.\n3. Optionally delete Binaries if needed.\n4. Regenerate Visual Studio project files.\n5. Build Development Editor | Win64 or run the low-memory script.\n\nMSB3073 / code 6 is only the final build failure; the important errors are C3859/C1076/C1060 above it.
